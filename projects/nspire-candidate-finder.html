NSPIRE Candidate Finder

A tool that automatically searches the web for certified home inspectors across target markets, uses AI to judge how good a fit each one is, and hands recruiters a clean, ranked list — replacing hours of manual directory searching with a process that runs on its own.

Python AI / LLMs Automation Excel Data Deduplication Tool Design

The Problem

Manual directory searching doesn't scale

Finding inspectors to recruit meant manually searching certification directories one market at a time, opening each listing by hand, and judging whether someone was worth reaching out to. As the candidate list grew into the hundreds, the same people kept getting looked at more than once, which was inefficient and easy to fix — the bigger issue was that none of it scaled past a handful of markets at a time.

The Approach

A search-and-review process that runs on its own

I built a system that runs the whole search-and-review process automatically: it searches each target market on a schedule, pulls candidate information off the page, and uses AI to score how strong a fit each person is, with a short written explanation of why, before it lands in a ranked spreadsheet ready for a recruiter to use.

Search markets → Find candidate pages → Pull out the details → AI reviews & scores fit → Ranked Excel spreadsheet

Technical Implementation

How it works

  • Searches each target market using a consistent, repeatable set of search terms, so coverage is predictable instead of random.
  • Reads each candidate's page and pulls out the details that matter — current role, employer, certification, experience — automatically.
  • Uses AI to score each candidate's fit and write a short note explaining the reasoning, the same way a recruiter would jot down first impressions.
  • Automatically recognizes when the same person shows up more than once (even under a slightly different listing) and combines them into one record instead of creating a duplicate.
  • Runs on multiple accounts in rotation to get more searches done per day within free usage limits.
  • Outputs everything into a polished, color-coded Excel file that's ready to hand off — no cleanup needed.
  • Packaged the whole thing as a simple double-click program for coworkers with no technical background, so anyone could run a search or refresh the spreadsheet without installing anything or touching a command line.

Results

Impact

What used to be manual, one-market-at-a-time searching now runs unattended. On its very first day of real use, it had already found 130+ qualified candidates across 8 target markets.

What I Learned

Reflections

  • Designing how a non-technical coworker would actually use the tool took more back-and-forth than the search logic itself — a command-line flag made sense to me, but the right answer for someone who'd never open a terminal turned out to be one simple question asked out loud when the program starts.
  • A fit score is only useful if a recruiter can tell whether to trust it. Having the AI write a short reason alongside every score, the same way a person would jot down a first impression, mattered more for actually getting the tool used than making the scoring itself more sophisticated.
  • Right before a deadline, I found a change I could make quickly but couldn't safely test in time — I shipped the version that already worked instead of gambling on an untested rebuild, and saved the improvement for the next round.
